DAY 23 – TEST CASES

What is a Test Case?

A test case is a document that contains steps to verify whether a feature works as expected.

Components:

1. Test Case ID
2. Test Case Name
3. Steps
4. Expected Result
5. Actual Result
6. Status

Characteristics of a Good Test Case:

- Clear
- Simple
- Repeatable
- Based on requirements
- One objective

Example Test Case
Test Case ID
TC001
Test Case Name
Login with valid credentials
Steps
Open Google.
Click Sign In.
Enter a valid email.
Click Next.
Enter the correct password.
Click Next.
Expected Result
User should successfully log in to the Google account.
Actual Result

Example:

User logged in successfully.
Status
PASSED

If login fails:

FAILED
Good Test Case vs Bad Test Case
❌ Bad
Test Login

Too vague.

✅ Good
Verify login using a valid email and valid password.

Specific and clear.

Characteristics of a Good Test Case

A good test case should be:

Clear
Simple
Easy to understand
Repeatable
Based on requirements
Have one objective

Anyone on the team should be able to execute it.
