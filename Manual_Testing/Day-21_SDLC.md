DAY 21 – SDLC

What is SDLC?
SDLC is the step-by-step process of developing software from planning to maintenance.

SDLC Flow:

Planning
    ↓
Analysis
    ↓
Design
    ↓
Implementation (Coding)
    ↓
Testing
    ↓
Maintenance



Phases:

1. Planning
   - Decide what to build
   - Budget
   - Timeline

2. Analysis
   - Gather customer requirements

3. Design
   - Create UI, database, and system design

4. Implementation
   - Developers write code

5. Testing
   - QA tests the software
   - Find and report bugs

6. Maintenance
   - Fix bugs
   - Improve performance
   - Add new features
