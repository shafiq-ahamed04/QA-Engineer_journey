DAY 20 – SOFTWARE TESTING

What is Software Testing?
Software Testing is the process of checking whether software works according to the requirements and finding defects before it reaches users.

Why do we test?
- To find defects
- To ensure software quality
- To improve customer satisfaction
- To reduce business risk

Goals of Testing
1. Find bugs
2. Ensure quality
3. Build customer confidence

Bug
A bug is a difference between the expected result and the actual result.

Testing vs Development

Developer
- Writes code
- Builds features
- Fixes bugs

Tester
- Tests software
- Finds defects
- Ensures quality
