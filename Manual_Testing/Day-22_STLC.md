DAY 22 – STLC

What is STLC?

STLC is the step-by-step process followed by QA Engineers to test software.


STLC Flow:

Requirement Analysis
        ↓
Test Planning
        ↓
Test Case Design
        ↓
Test Environment Setup
        ↓
Test Execution
        ↓
Test Closure


Phases:

1. Requirement Analysis
   - Understand what to test.

2. Test Planning
   - Decide how to test.

3. Test Case Design
   - Write test cases.

4. Test Environment Setup
   - Prepare the testing environment.

5. Test Execution
   - Execute test cases.
   - Report bugs.

6. Test Closure
   - Prepare reports.
   - Complete testing.
