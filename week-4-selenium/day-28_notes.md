1.What is WebDriver?
    Webdriver is an Browser Controller, used to control the browser and automate the interaction between the browser. 
Not only writing code, Everything in Selenium depends on it.

2.what is driver?
    Its like a robot, do whatever we say, python creates an object called driver. 
Every Selenium command starts with driver.

-> for better understanding,
     refer example code we done with file name as day-28_webdrivers.py in our week4 folder .

            driver.get() -> gets into the broswer
            driver.title() -> print title of the webpage
            driver.current_url() -> print URL of the webpage
            driver.quit() -> Close the enntire automation
            driver.close() -> close the current window/tabs/page

    ->These are the repeatedly used codes in Selenium.
